# Pi 十章面试自测题（闭卷）

用法：**合上讲义回答**。每题能脱稿讲 1–2 分钟才算过；答不上来或含糊的在
方框里标 `x`，攒起来找我逐章过。三类题：

- **概念** —— 是什么，必须能脱口而出
- **权衡** —— 为什么这么设计，面试官最爱追问
- **对照** —— 你的 lsm-harness 怎么落地的（把"学过"变成"做过"）

---

## 第 1 章 · 总览

- [ ] **概念**：Pi 的四个核心包分别管什么？一句话各说一个职责。

- [ ] **权衡**：为什么说"上下文干净"是编码 Agent 的核心竞争力？脏上下文的具体代价是什么？

- [ ] **对照**：你的项目三层（coding_agent → agent → ai）和 Pi 的对应关系？哪个测试保证依赖不倒流？

## 综合题（模拟终面）

- [ ] 从用户敲下回车到看到回复，完整讲一遍你项目里的链路（gateway → loop → 消息 → 事件 → 上下文 → 持久化），限时 3 分钟。
- [ ] 如果上下文窗口无限大，这套系统里哪些机制可以删掉？哪些仍然必要？（考"每个机制解决什么问题"）

- [ ] 如果要给系统加"流式输出"，哪些层要动、哪些层不用动？（考分层理解）
